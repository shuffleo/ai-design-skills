# Plan tradeoffs (step 8)

Before closing the implementation plan, use everything in the draft: JTBD, tools, workflow recall, validated research, intern answers, and [skill-writing.md](skill-writing.md).

## Surface tradeoffs

Identify **2–4 real tensions**, for example:

- **Breadth vs time** — full checklist vs what fits ~20 minutes.
- **MCP vs no MCP** — live Figma vs screenshot or export.
- **Strict script vs flexible steps** — deterministic output vs designer judgment.
- **Read-only vs actions** — report only vs creating/editing files.

## Ask directional questions

Turn each tradeoff into one question the designer can answer in a sentence. Examples:

- "Should the skill stop at a report, or also edit the Figma file?"
- "If Figma MCP is not connected, is screenshot input enough?"

Record each **decision** in the draft and in [../assets/skill-spec.md](../assets/skill-spec.md). Then finalize the TDD-first plan with eval prompts before `SKILL.md` — see [tdd-for-skills.md](tdd-for-skills.md).
