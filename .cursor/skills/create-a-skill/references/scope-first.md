# Pick one skill first (after ideas)

Run this right after the designer shares two ideas. Do not continue to JTBD or research until they pick one.

## Guide them on manageable scope

- One skill = one repeatable job, not an entire workflow.
- Workshop budget: ~20 minutes including test and iteration in a fresh agent.
- Compare both ideas: clearer input/output? easier to test? fewer tools required?

## Ask them to choose

Use AskQuestion or a direct ask: **Which one skill will you build first?** The other idea can become a later PR.

Record in the draft: both ideas verbatim, scope notes, and the **chosen skill** with one line why.
