# Intern-style extraction (step 6)

Ask **one question at a time**. Plain language. After each answer, check for gaps or vagueness — clarify before the next question.

## Question sequence

1. "If you had to train an intern to do this, what would you tell them first?"
2. "What does success look like?"
3. "How would you describe a job well done?"
4. "What are the steps, in order?"
5. "What mistakes do people make? What should they never do?"
6. "Can you give an example of a great result?"

## After each answer

- Did they mention **inputs** needed (files, links, context)?
- Did they describe **output shape** (sections, format, file type)?
- Any **rules** or **never-do** items missing?
- If vague, ask one short follow-up (e.g. "What would you check before calling it done?").

Capture answers **verbatim** in the draft. Pull **errors to prevent** and **wins to repeat** into the later skill plan.
